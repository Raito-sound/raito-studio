Tools/CARVE

WAVE EDITOR

CARVE

音を切り出し、
ループを仕上げる。

音声ファイルを開いて、必要な範囲を編集。フェードや音量の調整、ゲーム音楽のループ確認から書き出しまで、ブラウザで作業できる波形エディタです。

A wave editor that runs in your browser. Edit audio, shape fades, check loop seams and export WAV, OGG or MP3.

WAV / OGG Vorbis / MP3

FEATURES

波形を見ながら、
細部を整える。

選んだ範囲を編集
範囲の削除・コピー・挿入ペースト・新規ファイルへの切り出しに対応。ゼロクロスへのスナップを使って、選択位置を調整できます。
フェードと音量を調整
5種類のカーブからフェードイン・アウトを選択。目標ピーク値へのノーマライズと、dB指定のゲイン調整もできます。
ループのつながりを聴く
「Seam」でループ終端から先頭へのつながりを試聴。マーカーで指定したループ範囲を、OGGのLOOPSTART・LOOPLENGTHタグとして書き出せます。
用途に合う形式で書き出す
WAVは16-bit・24-bit・32-bit floatに対応。OGG VorbisとMP3にも書き出せます。読み込み時は元のサンプルレートを使用し、保持できない場合は警告を表示します。

QUICK START

ファイルを開いて、
波形を選ぶ。

  1. CARVEを開き、WAV・AIFF・FLAC・MP3などの音声ファイルをドロップするか「Open」で選びます。
  2. 波形をドラッグして範囲を選び、フェードや音量、ループ位置を調整します。
  3. 書き出し形式を選び、「Export」で音声ファイルを保存します。

音声はサーバーへアップロードされません。OGG・MP3の書き出しには、エンコーダーを読み込むための通信が必要です。細かな波形操作には、パソコンでの利用をおすすめします。
