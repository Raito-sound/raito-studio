RAITO STUDIO TOOLS / KEYS

KEYS

浮かんだフレーズを弾いて、練習して、残す。

メロディーを試し、メトロノームに合わせて練習し、短いアイデアを残すブラウザ鍵盤。サンプル音源のピアノと、合成音源のオルガンを選べます。

KEYSを使う ↗
料金
無料
音色
ピアノ / オルガン
書き出し
MIDI / WAV

できること

ピアノとオルガン
グランドピアノのサンプル音とオルガンを切り替え、音量・音色・残響を調整できます。
PCキーとタッチで演奏
PCのキー、マウス、タッチで演奏。オクターブ移動、移調、サステインに対応し、タッチでは鍵盤を横にスクロールできます。
練習の補助
30〜240 BPMのメトロノームに拍数・細分化の設定を搭載。鳴っている音名と代表的なコード名を表示します。
録音して持ち出す
最大90秒のテイクを録音し、カウントインやループ再生を使えます。MIDIとステレオ44.1kHz・16bit PCM WAVに書き出し可能。メトロノームは出力音声に含めません。

使い始めるには

  1. KEYSを開いてEnable audioを押します。PCキーで弾く場合は英語入力に切り替えます。
  2. ピアノかオルガンを選び、音量を調整して画面の鍵盤やPCキーで演奏します。
  3. レコーダーを開いて短いテイクを録音し、MIDIまたはWAVで保存します。

使う前に知っておくこと

新しく録音したテイクは前のテイクを置き換えます。複数のアイデアはファイルに書き出して残してください。PCキーボードは打鍵の強さを検出せず、同時押し数にも機器ごとの制限があります。MIDI鍵盤入力は未対応。コード表示は代表的な音の組み合わせを示す補助機能です。

ほかのツール

TALLY — 文章の文字数と、歌詞の音数を確かめる。CARVE — 音声を切り出し、フェードを整え、ループの継ぎ目を聴く。PITCH — ギターもベースも、見やすいメーターで合わせる。
